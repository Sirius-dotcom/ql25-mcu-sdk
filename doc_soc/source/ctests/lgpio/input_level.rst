input_level
===========

Function description:
---------------------
    * This demo shows LGPIO receiving test.
    * Configure two gpio_pins, LGPO_PIN0 as input and LGPO_PIN1 as input, and input force is set to 1.

Test result:
------------
If the value received by LGPIO_PIN is not equal to 0, printf pass, if not printf fail.

IO connection:
--------------
None

.. Note::
    The high level signal is provided from tb force.
