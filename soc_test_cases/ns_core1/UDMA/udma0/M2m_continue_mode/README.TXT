Function description:
    This demo shows the DMA communication in memory to memory continue mode, source and destination memory are in increasing address mode.
Test result:    
    After the communication is complete, counter the time, if destination buffer is equal to source data, and the finish times 
up to 100 times, printf pass, if not printf fail.
IO connection information:
    None
