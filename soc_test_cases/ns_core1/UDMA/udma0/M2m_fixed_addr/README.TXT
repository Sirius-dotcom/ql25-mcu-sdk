Function description:
    This demo shows the DMA communication in memory to memory mode, source and destination memory are in fixed address mode.
Test result:    
    After the communicate is complete, if destination buffer is equal to source data, then change the source and destination address by plus 1,
untile plus to 99, and every time, the destination buffer is equal to source data, then pass on, if not printf fail.
IO connection information:
    None
