Function description:
    This demo shows the DMA communication in memory to memory mode, source memory is in increasing address mode and destination 
is in fixed address.
Test result:    
    After the communication is complete, if destination buffer is equal to last source data, printf pass on, if not printf fail.
IO connection information:
    None
