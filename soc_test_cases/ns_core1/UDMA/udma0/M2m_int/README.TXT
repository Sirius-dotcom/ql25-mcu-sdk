Function description:
    This demo shows how to trigger full & half transfer interrupt, the source & destination address is increasing automatically, and dma working in normal mode.
Test result:
    If successfully trigger the interrupt and enter interrupt service function, and the destination buffer is equal to source data, printf pass on, if not printf fail.
IO connection information:
    None
