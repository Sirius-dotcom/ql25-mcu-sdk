Function description:
    This demo shows the linked-list function, if enable and configure the linked-list, after finishing the last transmission in repeated mode, then to start
new transmission according the linked-list configuration.
Test result:    
    After the communication is complete, if destination buffer is equal to last source data, printf pass on, if not printf fail.
IO connection information:
    None
