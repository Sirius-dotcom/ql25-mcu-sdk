Function description:
    This demo is used to test SPI write/read psram model in spi or xip mode.

Test result:
    the test results are printed out via USART PASS/FAIL/TODO.

IO Connection information:
    Connect QSPI_XIP0SCK    to psram SCK .
    Connect QSPI_XIP0CS     to psram CS  .
    Connect QSPI_XIP0DQ0    to psram DQ0 .
    Connect QSPI_XIP0DQ1    to psram DQ1 .
