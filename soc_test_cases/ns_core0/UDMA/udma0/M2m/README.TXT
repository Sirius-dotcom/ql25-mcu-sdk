Function description:
    This demo shows the DMA communication in memory to memory mode, source and destination memory are in increasing address mode.
Test result:    
    After the communication is complete, if the data writted to buffer by DMA is same as the source data, printf pass on, if not printf fail.
IO connection information:
    None
