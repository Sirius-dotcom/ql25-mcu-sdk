Function description:
    This demo shows the DMA communication in memory to memory mode, source memory is in fixed address mode and destination 
is in increasing mode address.
Test result:    
    After the communication is complete, if every destination buffer data is equal to source data, printf pass on, if not printf fail.
IO connection information:
    None
