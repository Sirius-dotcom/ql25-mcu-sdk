Function description:
    This demo shows the I2C1 master receiving and I3 slave transmitting in cpu mode.

Test result:
    If the data of I2C1 received is equal to I3 transmitted, print pass, if not print fail.

IO Connection information:
    Connect I2C1 SCL    to I3 SCL .
    Connect I2C1 SDA    to I3 SDA .
